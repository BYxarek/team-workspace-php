# Contributing / Участие в разработке

1. Fork the repository / Сделайте fork.
2. Create a feature branch / Создайте отдельную ветку.
3. Do not commit `config.php` or credentials / Не добавляйте `config.php` и секреты.
4. Run `composer install`, `composer validate --strict` and PHP syntax checks before opening a PR / Перед PR установите зависимости и запустите Composer/PHP-проверки.
5. Keep UI changes responsive for desktop and mobile / Проверяйте desktop и mobile UI.
