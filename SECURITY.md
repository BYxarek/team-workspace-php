# Security Policy / Политика безопасности

## Reporting / Сообщение об уязвимостях

Please do not publish sensitive vulnerability details in a public issue. Contact the repository owner privately through their GitHub profile first.

Не публикуйте детали критических уязвимостей в открытом issue. Сначала свяжитесь с владельцем репозитория приватным способом через профиль GitHub.

## Secrets

Never commit `config.php`, database passwords, FTP/SSH credentials, API keys, session secrets, private URLs containing tokens, or production database dumps.

Никогда не коммитьте `config.php`, пароли БД, FTP/SSH-реквизиты, API-ключи, секреты сессий, приватные URL с токенами или production-дампы базы.
